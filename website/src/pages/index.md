# RogueMod

A C#-first mod loader and manager for Deadzone: Rogue, built on RE-UE4SS.

- **[Documentation](/docs)** — quick starts for every package kind, the managed API guide, packaging, architecture, and development docs.
- **[API Reference](/api)** — generated from the XML documentation comments shipped with `RogueMod.Abstractions`, `RogueMod.Sdk`, and the generated game SDK.
- **[GitHub](https://github.com/freakdaniel/RogueMod)** — source, issues, and releases.
